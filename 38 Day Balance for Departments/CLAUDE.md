# 38 Day Balance for Departments

This project coordinates the Chemistry and GLAM work associated with moving departments to 38-day leave balances.

## Working rules

- Keep this folder as the single working location for the project.
- Put supplied source files in `source-files/`.
- Put analysis and reconciliation work in `working/`.
- Put user-ready outputs in `outputs/`.
- Do not commit raw email bodies, credentials, or unrelated mailbox content.
- Update `HANDOVER.md` whenever the project state or next action changes.
